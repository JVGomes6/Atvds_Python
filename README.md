#  Atvds_Python

Repositório dedicado ao armazenamento e desenvolvimento de listas de exercícios em Python realizadas durante a graduação na Universidade Federal do Paraná (UFPR).

## Sobre o Projeto

Este repositório reúne atividades práticas voltadas ao estudo de algoritmos, lógica de programação e estruturas fundamentais da linguagem Python.

Os exercícios foram desenvolvidos com o objetivo de consolidar conceitos importantes da programação, proporcionando prática na resolução de problemas computacionais e no desenvolvimento do raciocínio lógico.

##  Conteúdos Abordados

- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`for`, `while`)
- Vetores e matrizes
- Funções e procedimentos
- Manipulação de strings
- Manipulação de arquivos
- Algoritmos matemáticos
- Busca e ordenação
- Exercícios de lógica de programação
- Introdução à programação orientada a problemas
